空间镜 / DiskLens · 免费社区版安装说明

支持 macOS 12 及以上，通用 App 包含 Apple 芯片与 Intel 架构。
Intel 尚未实机验证。

安装 DMG
1. 核对下载来源与发布页给出的 SHA-256。
   命令行可用：shasum -a 256 -c SHA256SUMS（在安装包与校验文件所在目录运行）。
2. 打开 DMG，将“空间镜.app”拖入 Applications 快捷方式。
3. 弹出磁盘映像，再从“应用程序”打开空间镜。

本版无付费 Apple 开发者账号，使用本地临时签名（ad-hoc），未经苹果公证。
签名完整性检查通过，不等于苹果认证了开发者，也不等于通过了公证。
其他 Mac 下载后可能出现无法验证开发者等提示，Homebrew 安装也不会消除提示。

如果系统阻止首次打开
确认来源和校验值可信后，先尝试从“应用程序”打开一次，再由你自行前往：
系统设置 → 隐私与安全性 → 找到刚才被阻止的应用 → 仍要打开。
具体按钮随 macOS 版本变化，并不保证所有拦截类型都可按此方式放行。
如果提示恶意软件、文件损坏或组织策略阻止运行，请停止并核对来源、重新下载或自行从源码构建。
不要全局关闭 Gatekeeper；本项目不会提供自动移除隔离属性的安装脚本。

Apple 官方说明：https://support.apple.com/en-us/102445

权限
打开 App 不需要管理员权限。读取受保护目录时可能被 macOS 拒绝。
完整磁盘访问权限由你自己决定是否授予；App 不会自动打开，也不能保证授权后没有读取盲区。
“内部数据盘分析”不包括所有系统卷、VM 卷和其他挂载卷的逐文件扫描。

清理
文件由你逐项审核，并经原生确认后移入系统废纸篓。
本 App 不会清空废纸篓，不提供永久删除。
Docker 虚拟磁盘、个人原件、凭据等默认保护，不应直接删除。
恢复时原路径已有文件不会覆盖；清空废纸篓后不能通过 App 恢复。

卸载
退出空间镜，将“应用程序”中的空间镜.app 移到废纸篓。
Homebrew 用户可以使用 brew uninstall --cask disk-lens。
卸载不删除用户资料、偏好或清理历史。

本 DMG 没有捆绑个人扫描结果、账户、清理历史或其他用户数据。

如果已经手动安装过空间镜，改用 Homebrew 前先退出并备份或移走旧 App；不要删除个人资料和清理记录。
